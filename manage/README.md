# ניהול מולטיוורס – אפליקציה לטלפון

אפליקציית ווב (PWA) לניהול האתר מהטלפון, עם הלוגו של מולטיוורס כסמל במסך הבית.

**הכתובת:** https://multiverse-manage.multiversesite.workers.dev/ (וגם `multiversesite.com/manage/` מעביר אליה).

## מה יש בה
- **בית:** כמה תגובות וטיוטות מחכות, האם האתר באוויר או מתעדכן (וכפתור לבנייה מחדש), הסוכן מקבוצת הפייסבוק
  (מתי הסריקה הבאה, מה הועבר ומה דולג), הצפיות של היום ושל השבוע, ומה השתנה לאחרונה.
- **פוסטים:** טיוטות ופרסום בלחיצה, פוסטים אחרונים, חיפוש בכל הפוסטים באתר, שיתוף, החזרה לטיוטה,
  וקישור ישיר לעריכה של כל פוסט ב-Pages CMS.
- **פוסט חדש:** כותרת, תמונה ראשית (מוקטנת בטלפון ל-WebP), כותב, קטגוריות, טקסט, תקציר ותגיות.
  "פרסום" מעלה לאתר מיד, "שמירה כטיוטה" שומר ב-`content/posts/` כמו Pages CMS. הטקסט נשמר בטלפון בזמן הכתיבה.
- **תגובות:** אישור, אישור של כולן במכה אחת, הסתרה ומחיקה.
- **צפיות:** נתונים מ-GoatCounter (צריך מפתח "Read statistics" שמודבק פעם אחת באפליקציה).
- **כלים:** קישורים לכל השאר – Pages CMS (פוסטים, עמודים, תמונות, כותבים, קטגוריות, הגדרות, עורכים),
  פייסבוק, הסוכן ב-Claude, Brevo, GoatCounter, Cloudflare, WordPress.com (הדומיין), GitHub.

## איך זה עובד
- קבצים סטטיים בלבד ב-`manage/public/` (HTML, CSS, JavaScript בלי ספריות ובלי שלב בנייה).
- האפליקציה עובדת מול המאגר דרך GitHub REST API, עם מפתח גישה (fine-grained token) שנשמר רק בטלפון:
  Contents: Read and write, Actions: Read and write, רק למאגר `multiversesite`.
  כל שינוי הוא commit אחד ל-`main`, ולכן האתר נבנה מחדש לבד.
- "פרסום" של טיוטה ו"החזרה לטיוטה" מפעילים את אותו `publish.yml` שהכפתורים ב-Pages CMS מפעילים.
- היא מתארחת בכתובת נפרדת מהאתר (Cloudflare Workers) כדי שהסקריפטים שהאתר טוען
  (פייסבוק, X, אינסטגרם, Brevo, סטטיסטיקות) לא יוכלו לגשת למפתח.
- הפריסה: `.github/workflows/manage-app.yml` מריץ `wrangler deploy` בתיקייה הזאת אחרי כל שינוי ב-`manage/`,
  עם הסודות `CLOUDFLARE_API_TOKEN` ו-`CLOUDFLARE_ACCOUNT_ID` של שירות התגובות.
- הגופנים IBM Plex Sans Hebrew ו-Karantina מוגשים מהאפליקציה עצמה (רישיון SIL OFL, ב-`public/fonts/`).

## בדיקה מקומית
```
python3 -m http.server -d manage/public 8765
```
ופותחים http://127.0.0.1:8765/ (ה-service worker נרשם רק ב-https).
